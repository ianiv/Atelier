#
#   path-prefix | unit suites | automation checks

# A prefix is a shell pattern matched against the start of the repo-relative path; the longest
# matching line wins. Suites are struct names (comma-separated); `all` runs the whole suite, `smoke`
# the smoke set, `none` nothing. Checks are the app's scripted-run flags, printed as command lines
# (run with --checks). `Scripts/test.sh --lint-map` fails when a folder of Sources/Atelier, a suite
# or a check flag is missing here, or a name here no longer exists.
