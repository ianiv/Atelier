# Roadmap

Planned work that isn't built yet. Items marked **User request** or **User-reported bug** came from Atelier users.

## History

- Adjustable thumbnail sizes in the History grid view.
- Let the History screen's right pane be resized wider; the current maximum width is too small.

## LoRAs

- **User request:** when a LoRA is selected, use its strength from `custom_lora.json` as the default, and its lower and upper limits as the slider range, instead of defaulting every LoRA to 1. Some Draw Things users (for example with the DT LoRA Config Editor script) have set these carefully in Draw Things.

## Presets

- **User-reported bug:** Presets ▸ Import Preset from `custom_configs.json` creates duplicate copies of many presets when importing again (for example after editing the JSON). The imported presets show under "Other Models", Export and Delete.
- **User request:** allow choosing a greyed-out preset whose model isn't installed, then switching to a local model, as Draw Things allows. Atelier already lets you pick a preset whose LoRAs are missing and then download them or change the selection, but not a preset whose model is missing.
