1. [Getting started](getting-started.md): what you need, building and installing the app, pointing it at your models, and making your first image.
2. [Creating images](creating-images.md): the Create screen, the prompt, size and seed, the settings inspector, presets, image to image and the moodboard.
3. [History and projects](history.md): browsing what you made, reusing settings, exporting and deleting, and switching projects.

5. [Settings](settings.md): the models folder and the performance options.
6. [Atelier for agents (MCP)](../MCP.md): letting Claude Code and other agents generate images with your models.

## Keyboard shortcuts

| Shortcut | Action |
| --- | --- |
| ⌘↩ or Return in the prompt | Generate |
| ⌥↩ in the prompt | New line |
| Esc | Stop the running generation |
| ⌘L | Focus the prompt |
| ⌘R | Roll a new seed |
| ⌘↑ / ⌘↓ | Previous / next recent prompt |
| ⌘O | Open an image onto the canvas |
| ⇧⌘V | Paste an image onto the canvas |
| ⌘+ / ⌘− | Zoom the canvas in / out |
| ⌘9 | Zoom to fit |
| ⌘0 | Actual size |
| ⌥⌘I | Show or hide the inspector |
| ⌘, | Settings |
