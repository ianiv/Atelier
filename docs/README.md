# Atelier user guide

1. [Getting started](getting-started.md): what you need, building and installing the app, pointing it at your models, and making your first image.
2. [Creating images](creating-images.md): the Create screen, the prompt, size and seed, the settings inspector, presets, image to image and the moodboard.
3. [Making videos](video.md): video models, length, starting from an image, audio, and watching and reusing videos.
4. [Putting videos together](timeline.md): the Timeline screen, trimming and splitting clips, continuing from any frame, and exporting one longer video.
5. [The queue](queue.md): queuing images while one runs, making several at once, pausing, reordering and cancelling.
6. [History and projects](history.md): browsing what you made, reusing settings, exporting and deleting, and switching projects.
7. [Models and LoRAs](models-and-loras.md): downloading models, importing checkpoints and LoRAs, and making 8-bit copies of MOSS models.
8. [Settings](settings.md): the models folder, the output folder and the performance options.
9. [Atelier for agents (MCP)](../MCP.md): letting Claude Code and other agents generate images and videos with your models (Mac only).

The iPad version works the same way, with a few differences noted under "On iPad" in each page; see [Atelier on iPad](getting-started.md#atelier-on-ipad) to build and install it.

## Keyboard shortcuts

| Shortcut | Action |
| --- | --- |
| ⌘↩ or Return in the prompt | Generate |
| ⌥↩ in the prompt | New line |
| Esc | Stop the running image (the queue goes on) |
| ⌘L | Focus the prompt |
| ⌘R | Roll a new seed |
| ⌘↑ / ⌘↓ | Previous / next recent prompt |
| ⌘O | Open an image onto the canvas |
| ⇧⌘V | Paste an image onto the canvas |
| ⌘+ / ⌘− | Zoom the canvas (or Timeline's track) in / out |
| ⌘9 | Zoom to fit |
| Space, ← / →, J / K / L | Timeline: play or pause, step a frame, play backwards / pause / play |
| ⌘B | Timeline: split the clip at the playhead |
| ⌘0 | Actual size |
| ⌥⌘I | Show or hide the inspector |
| ⌘, | Settings |

On iPad, the same shortcuts work with a hardware keyboard.
